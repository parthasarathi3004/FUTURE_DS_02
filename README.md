# FUTURE_DS_02
Customer churn and retention analysis using Power BI, incorporating cohort analysis to uncover trends and deliver actionable insights for subscription-based businesses.
📌 Project Overview

This project focuses on analyzing customer churn and retention for a subscription-based business using Power BI. The aim is to identify churn drivers, understand retention patterns, and derive actionable insights to reduce customer churn.

🛠 Tools Used

Power BI

Excel

DAX

📊 Key Metrics

Total Customers

Churn Rate

Retention Rate

📈 Dashboard Highlights

Churn analysis by plan type, usage level, and region

Cohort-based retention analysis

Interactive filters for dynamic insights

🔍 Key Insights

Low-usage customers show higher churn

Basic plan users churn more than Premium users

Retention decreases after the initial months

💡 Business Recommendations

Enhance onboarding and engagement

Provide incentives for Basic plan users

Improve customer support and loyalty programs
